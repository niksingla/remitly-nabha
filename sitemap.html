How this site is built

FileWhat it does
css/styles.cssThe whole design system — tokens, components, layout and responsive rules.
js/layout.jsBuilds the header, navigation and footer and injects them into every page.
js/main.jsCalculator, converter, tabs, accordions, country search and the demo form guards.
*.htmlOne file per page, each loading the two scripts above.

No frameworks, no build step and no external requests. Open any HTML file directly in a browser and it works.
