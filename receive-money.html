Questions about receiving

Not for a straightforward bank deposit, wallet credit or cash pickup — the sender handles it all. You would only create an account if you want a multi-currency balance, a card, or payment request links.

A current government-issued photo ID whose name matches the recipient name on the transfer exactly, plus the reference number. Agents turn away mismatched names, so it is worth checking spelling with the sender first.

No fee is taken from the recipient in this model — the sender covers it. A receiving bank may still apply its own inbound credit charge depending on the account.

You get a text when the sender confirms the transfer and another when it is ready or deposited. If you have an account, the same updates appear as push notifications.
